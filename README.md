## Circle Clicker
A reaction game with a server-side scoreboard. A circle sits in the play area and moves around everytime you press it. The goal is to press it as  much as possible in 30 secconds. 

App uses flexbox throughout. 

To use the application go to: https://a2-maxgingold.onrender.com
or run it locally using node Server.js and then go to: Then open http://localhost:3000.

The scoreboard data lives in memory so when the server resets so does it. 

## Technical Achievements
It is a singple page app users submit data when they finish the game. The server sends back the data including the derived value of hit/sec.

Users can delete or change the name of a score entry on the scoreboard page.
